# Northstar CRM — Enterprise CRM Platform

A responsive CRM frontend built with React, TypeScript, Vite, Redux Toolkit, Tailwind CSS and Recharts. It includes sample data and browser LocalStorage persistence.

## Run locally
1. Install Node.js 18+.
2. Extract this folder.
3. Open a terminal in the project folder.
4. Run `npm install`
5. Run `npm run dev`
6. Open the local URL printed by Vite.

## Production build
Run `npm run build`, then `npm run preview`.

## Included modules
Dashboard analytics, leads CRUD, sales pipeline, customer profiles, tasks, activity tracking, reports, team, notifications and settings.

## Notes
This is a frontend demonstration with seeded sample records. Authentication and backend/API integrations are not included.
